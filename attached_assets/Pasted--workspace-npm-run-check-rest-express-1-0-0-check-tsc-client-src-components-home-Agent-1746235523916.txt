Why this works:
JSX expressions must return a ReactNode.

When you use && chains directly in JSX, TypeScript considers the final result unknown if it can’t infer that it definitely returns valid JSX.

Wrapping each block in a ternary like condition ? <JSX /> : null guarantees a valid return type.
